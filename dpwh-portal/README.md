# DPWH Portal

This project is a web application designed to manage and display local DPWH (Department of Public Works and Highways) projects. It features a mobile-first layout and is built using Vite, React, and Tailwind CSS.

## Features

- **Dashboard Screen**: Displays a list of local DPWH projects with traffic light risk flags indicating their status:
  - 🟢 Good
  - 🟡 Review
  - 🔴 High Risk

- **Citizen Upload Form**: Allows citizens to upload images related to projects. It includes:
  - A camera trigger for capturing images
  - A dropdown selection for nearby projects
  - A text area for additional notes

- **Supplier Directory**: Showcases materials such as cement and rebar along with their local pricing in a clean layout.

## Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/dpwh-portal.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd dpwh-portal
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Open your browser** and go to `http://localhost:3000` to view the application.
